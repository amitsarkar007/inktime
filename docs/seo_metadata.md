## Short Description

InkTime is a calm monochrome dashboard with 24-hour time, GPS weather, forecast, sunrise, sunset, air quality, pollen and world clocks.

## Long Description

InkTime is a Flutter mobile and desktop dashboard designed for e-ink friendly readability. It combines a large 24-hour clock with local date, GPS-based weather, rest-of-day and 5 day forecasts, sunrise and sunset details, daylight duration, UV index, air quality, pollen, pressure and saved world clocks.

The interface is intentionally monochrome, spacious and low-noise. Weather data comes from Open-Meteo, so there are no paid API keys or account requirements for weather access.
